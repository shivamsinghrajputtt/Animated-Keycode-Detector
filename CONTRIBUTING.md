# Contributing

Thanks for your interest in contributing to Animated Keycode Detector.

## Getting started

1. Fork the repository.
2. Clone your fork locally.
3. Create a focused feature or fix branch.
4. Make your changes and keep the implementation dependency-light.
5. Run the test suite with `npm test`.
6. Open a pull request against `main` with a clear description of the change.

## Development guidelines

- Keep browser behavior compatible with modern browsers.
- Prefer small, focused changes over unrelated refactors.
- Preserve the existing keyboard-event behavior unless the change explicitly requires it.
- Add or update tests when changing event-normalization logic.
- Keep accessibility and responsive behavior in mind for UI changes.

## Pull requests

Please explain what changed, why it changed, and how you verified it. Pull requests should pass the repository CI checks before merging.

## Questions and bugs

For bugs or feature discussions, open an issue with clear reproduction steps and expected behavior.
