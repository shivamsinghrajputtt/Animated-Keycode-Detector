# Security Policy

## Supported versions

The latest version on the `main` branch is the supported version.

## Reporting a vulnerability

Please do not disclose security-sensitive details in a public issue.

If you discover a security vulnerability, report it privately through GitHub's repository security reporting features when available. Include enough information to reproduce the issue and explain its potential impact.

Please allow reasonable time for investigation and remediation before publicly disclosing the issue.

## Scope

This project is a client-side static web application. Reports should focus on security issues that can affect users of the application, the repository, its build/CI configuration, or its published GitHub Pages deployment.
